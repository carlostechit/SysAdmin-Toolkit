# SysAdmin Toolkit 🛠️

Colección de scripts, configuraciones y automatizaciones para gestión de infraestructura, despliegues y contenedores.

## Stack Tecnológico
- **Lenguajes:** PowerShell, Bash (WSL2).
- **Virtualización:** VMware Workstation Pro.
- **Orquestación:** Docker, Docker Compose.
- **Entorno:** Windows 11 / WSL2.

## Estructura del Repo
- `/docker-services`: Configuraciones de contenedores (Nginx, MySQL, etc).
- `/scripts`: Automatización de tareas repetitivas en Windows/Linux.
- `/docs`: Documentación técnica de despliegues.
